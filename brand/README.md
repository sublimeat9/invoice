# Marca

Identidad visual de la aplicación: una hoja de factura blanca con líneas de detalle sobre un
cuadrado azul de esquinas redondeadas.

- **`logo-mark.svg`**: el símbolo solo, cuadrado. Es el ícono de la aplicación y el favicon.
- **`logo.svg`**: el símbolo junto al nombre «Invoicing», para encabezados y documentación.
- **`colors.css`**: la paleta en sus versiones clara y oscura.

## Paleta

Un solo color de acento, sobrio, sobre neutros; los estados usan verde, ámbar y rojo.

| Token | Claro | Oscuro |
| --- | --- | --- |
| Acento | `#2f4fd8` | `#7c97f5` |
| Tinta | `#14181f` | `#e8ebf0` |
| Fondo | `#f7f8fa` | `#0e1116` |
| Correcto | `#137a4b` | `#4cc38a` |
| Aviso | `#946200` | `#e3b341` |
| Error | `#b42318` | `#f97066` |

Tipografía: Inter, o la fuente de interfaz del sistema si no está disponible.
